hledger-web Demo Page

Demo Mode: This is a static demo page. In the actual hledger-web application, clicking sidebar or transaction links would navigate to different pages showing filtered data.

What would happen in the real application:

  • Sidebar account links: Would show a register view filtered to that account
  • Transaction links: Would show detailed transaction information
  • Journal link: Would show the general journal with all transactions
  • Search functionality: Would filter transactions based on search patterns
Note: Server-side features are not available in this static demo. This is only for testing CSS and JavaScript functionality.
